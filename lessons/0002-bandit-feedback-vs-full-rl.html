Lesson 02 · Adaptive Agent Router

The missing piece in full RL

Your mapping was right. The one refinement is that full RL is defined by action-dependent future states and rewards—not simply by whether we “modify” an environment.

You already have: context = task features, action = chosen strategy, feedback = result of that strategy. This lesson adds the state-transition test.

The state-transition test

Contextual bandit

The current context arrives, one action is selected, feedback is observed, and the decision ends.

xₜ → aₜ → rₜ → end

Full reinforcement learning

The action changes what state comes next, and that next state affects later decisions and rewards.

sₜ → aₜ → sₜ₊₁ → aₜ₊₁ → return

Ask: “Does the chosen action determine the next decision situation?” In the router, choosing tool instead of direct changes the current answer and reward, but it does not determine what the next task will be. Therefore the project is a one-step contextual bandit.

This is called bandit feedback: you see the payoff for the arm you pulled, not the payoffs of the arms you did not pull. The full benchmark deliberately runs all three strategies, but that is an offline comparison—not honest online feedback for one routing decision.

One subtle point

The router's policy does change after each task because its estimates are updated. That makes the overall experiment sequential, but it does not make the task environment a full RL environment. The policy learns across rounds; the task does not become a new state caused by the previous action.
