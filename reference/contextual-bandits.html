Quick reference

Contextual bandits

A contextual bandit makes one action choice using the current context, observes feedback for that chosen action, and improves future choices.

x_t = current context a_t = chosen action r_t = observed reward choose: a_t = policy(x_t) learn: policy ← policy + feedback(x_t, a_t, r_t)

Three levels

Multi-armed bandit

No context. Learn one average value per arm.

Contextual bandit

Use context. Learn which arm fits this situation.

Full RL

Actions change future states and can produce delayed rewards.

Router translation

Context

Category, prompt length, numbers, and requested fields.

Actions

direct, strong, and tool.

Feedback

Quality, cost, latency, and the derived reward.

Algorithm memory hooks

  • Epsilon-greedy: randomly explore with probability ε; otherwise exploit the best average action.
  • UCB: estimated value plus an uncertainty bonus.
  • LinUCB: predicted linear reward plus a context-dependent confidence bonus.
